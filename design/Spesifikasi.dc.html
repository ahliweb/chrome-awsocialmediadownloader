Aksesibilitas (REQ-008 · WCAG 2.2 AA)

1. Urutan fokus: (i) → Muat ulang → Unduh baris 1…n → Kebijakan privasi.
2. Fokus awal ke tombol utama status; Esc menutup popup (perilaku bawaan Chrome).
3. Semua kontrol adalah button atau a asli; tombol ikon wajib aria-label.
4. Perubahan status diumumkan via role="status" aria-live="polite"; galat via role="alert".
5. Kontras teks ≥ 4,5:1 di kedua tema (nilai terukur di panel warna).
6. Jenis trek dibedakan dengan teks dan ikon, bukan warna saja.
7. Animasi progres dimatikan bila prefers-reduced-motion aktif.

Rencana screenshot toko (1280 × 800, untuk #18)

1. Daftar media di atas halaman Reels — nilai utama (contoh di kanvas).
2. Trek terpisah + panduan menggabungkan — kejujuran soal batasan.
3. Janji privasi: tanpa telemetri, tanpa server, sesi tidak dibaca.
4. Pemberitahuan hak — menunjukkan kepatuhan pada kebijakan CWS.
5. Mode gelap + English — aksesibilitas dan dwibahasa.
Semua screenshot memakai video milik pemilik repo; bahasa listing menunggu keputusan #4.
